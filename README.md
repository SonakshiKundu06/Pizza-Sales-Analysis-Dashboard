# 🍕 Pizza Sales Analysis Dashboard

## 📄 Project Overview
This Power BI dashboard provides a detailed analysis of pizza sales performance.  
It helps uncover insights into **sales trends, profit distribution, discounts, and customer behavior** — empowering better business decisions.

---

## 🎯 Objectives
- Analyze total sales amount by year
- Compare discounts and prices across pizza categories
- Track profits by region
- Understand how gender and payment mode affect discounts and profit
- Highlight top-performing pizza types and underperforming ones

---

## 🧠 Key Insights
- **Sales Trend:** Sales peaked in 2021 and slightly declined afterward.  
- **Top Performer:** *BBQ Chicken Pizza* generated the highest sales.  
- **Profit by Region:** The Central region contributed the most to profits (~51%).  
- **Customer Patterns:** Females using cards/UPI contributed more to total profit.  
- **Discount Analysis:** Certain categories offered high discounts but lower profitability.
